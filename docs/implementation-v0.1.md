# V0.1 实现说明与规则边界

本文补充 [产品设计大纲](v0.1.md)，记录首个实现版本的具体选择。

## 默认体系

采用独立命名的“五张高花 · Five-card majors”教学预设，不声称实现完整 SAYC。

| 项目 | 实现 |
|---|---|
| 位置 | 用户固定南家；其余三家自动叫牌 |
| 常规开叫 | 12–21 HCP；五张高花，低花至少三张 |
| 低花选择 | 较长低花；3–3 先梅花，4–4 先方块 |
| 1NT | 默认 15–17，可选 12–14；4333、4432、5332 |
| 五张高花与 1NT | 默认不允许，可打开 |
| 弱二 | 可选；6–10 HCP、六张方块／红心／黑桃，至少两张 A/K/Q |
| 评价 | 使用 HCP 与张数；不计算分配点、输墩或牌力修正 |
| 高花直接成局加叫 | 教学自然定义为 13–15 HCP、至少四张支持；不等同于 SAYC 阻击性直接加叫 |

已实现 1NT 之外的部分均型手牌仍按本教学一阶花色范围处理；2NT 开叫、强 2♣ 及其后续没有实现。自然叫牌也只覆盖下述分支。

## 已实现进程

### 无干扰 1NT

- 直接 Pass、2NT 邀局、3NT 成局。
- 教学邀局阈值 `25 − 无将最高限`，成局阈值 `25 − 无将最低限`。
- 常规 Stayman：承诺至少一门四张高花及邀局实力；不使用垃圾 Stayman。
- Stayman 答叫：先显示红心，再黑桃，否则人工 2♦。
- 已找到高花配合后的邀局与成局。
- 没有配合时返回无将；开叫者同时四四高花时，可在显示红心后找到黑桃配合。
- 雅各比转移：2♦ → 2♥、2♥ → 2♠；不超接受。
- 转移后的弱牌止叫；五张高花的无将邀局／成局选择；六张以上高花的花色邀局／成局。
- 开叫者在最高限接受邀局，否则拒绝；这是一项明确的教学决策策略。
- 可选自然梅花止叫、自然二阶方块／高花止叫，与同进程的人工约定进行冲突校验。

高点力应叫手需要满贯探索时不自动止于成局。复杂双套展示、干扰后的约定、满贯和问叫暂不支持。

### 自然花色叫牌

- 五张高花与较长低花开叫。
- 简单加叫、限制性高花加叫、教学自然高花成局加叫。
- 部分一盖一新花色应叫，非逼叫 1NT 应叫。
- 最低限四张支持高花、均型 1NT 再叫、六张开叫套的最低限再叫。
- 已实现再叫后的简单止叫与成局分支。
- 自然一阶争叫、部分竞争性加叫和停叫。
- 弱二后的 Pass 与高花直接成局。

逆叫、跳叫、新花色二盖一、强牌再叫、技术性加倍、复杂竞争、弱二问叫等未实现。引擎找不到符合条件的叫品时停止，并说明缺少的规则类别。

## 规则可信度

- `decide()` 接口只接收行动牌手的一手牌、座位、公开历史及其体系。
- 四家手牌的界面可见性不会改变引擎输入。
- 历史条目同时保存规则标识、公开含义和本手理由。
- 体系快照保存在牌局中；更改体系不影响旧牌局。
- 用户叫品如果合法但不满足已定义条件，标记“与叫品条件不符”；合法但未定义的叫品标记“暂无法评价”，停止自动继续。
- “符合教学策略”和“满足叫品条件”不表示唯一最佳叫品，也不代表实际定约一定能完成。
- 加倍／再加倍的合法性已实现，但战略含义不在首版覆盖范围。

## 练习与数据

- 自由练习不限制发牌，可能进入未覆盖进程。
- 开叫练习使南家从首轮行动开始。
- 无将、Stayman、转移主题生成北家符合 1NT 条件的手牌，并控制东西牌力，使练习集中在无干扰进程。
- 每手 13 张、全副 52 张且不重复，总 HCP 为 40。
- 本地记录上限 500 副，体系上限 100 套；到达记录上限后保留最近记录。可通过备份长期保存。
- 支持单副牌／体系导入导出、完整备份合并、分享含体系快照的牌局链接。
- 导入解释不可信任，依据手牌和历史重新生成。牌张重复、非法顺序、非法叫品和不支持的文件版本均拒绝导入。
- 指定局面编辑器不在本次实现中；可导入符合格式的已有牌局继续练习。

## 界面与部署

- 原生 JavaScript ES modules，无运行时包依赖、无后端。
- 中英文五页界面，手机／桌面响应式布局。
- 可选在线字体，提供系统字体回退。
- GitHub Pages Actions 配置已提供；尚需仓库启用 Pages 的 Actions 来源并推送后才会公开上线。
