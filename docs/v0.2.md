# Bridge Studio V0.2

发布日期：2026-10-23

## 修复目标

随机发牌时，用户始终只控制南家，北、东、西自动叫牌，直到四家不叫或定约后的三家连续不叫。不再因为缺少教学规则提前结束，也不再要求用户代电脑操作。

## 叫牌与教学反馈

- 优先使用所选体系中已有的规则和约定叫。
- 规则无法给出建议时，使用保守自然续叫：根据本手、公开叫牌和已显示的最低点力估计，考虑自然长套应叫、争叫、支持搭档、成局或接受当前定约。
- 人工叫品不擅自当作自然花色；没有可靠定义时不编造约定含义。
- 自然续叫标记为“不评分”，不将启发式建议判为唯一正确答案。南家选择未定义叫品也能继续，不自动记为错题。
- 续叫决策仍只接收当前牌手的一手牌，不读取其他手牌。
- 自动续叫不等于完整实现所有桥牌约定或专家级叫牌。专项训练保留既有教学规则边界；随机发牌的完整运行与教学评分范围分开处理。

## 界面与语言

- Auction 移至牌桌中央。
- 桌面叫牌器位于右侧，保持在可视区域；移动端练习时固定在底部，方便直接选择叫品。
- 牌局结束后保留禁用叫牌器，复盘单独显示。
- 内置体系名按界面语言显示，英文固定界面不混入中文。用户自定义体系名保留原样。
- 中文人名约定叫附原英文，例如斯台曼（Stayman）、雅各比（Jacoby）转移叫、迈克尔斯（Michaels）扣叫。
- 页面版本号更新为 V0.2，包版本为 0.2.0。

## 数据兼容

沿用原本本地存储键和 schema 1，保留现有体系、记录和笔记。导入与分享恢复时重新计算叫品解释和反馈。支持较长但合法的叫牌历史，上限为 512 个叫品。

历史上因教学范围停止的随机牌局提供“继续自动叫牌”入口，以新的练习记录续叫；已有复盘记录保留。手动停止的牌局仍保持停止。

## 验证与发布

- `node --test`：原规则回归和 V0.2 续叫测试。
- 新增 1,080 副可复现牌局，覆盖三套南北／东西体系组合、四个发牌位置和南家选择非建议叫品；检查合法性、正常结束、保存恢复、分享编码和最终定约。
- 复现 1♣ — 1♠ 后东家无法自动决定的原始问题，验证可自然续叫。
- 浏览器验收覆盖随机发牌、用户座位限制、中英文、桌面与移动端叫牌器位置，以及既有练习、撤回、复盘、导入导出和分享。
- 推送 `main` 触发现有 GitHub Pages 工作流；测试通过后发布静态资源。
